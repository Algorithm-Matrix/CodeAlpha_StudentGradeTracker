# CodeAlpha_StudentGradeTracker

A Java console application created for the **CodeAlpha Internship** task. This program allows users to input student names and their respective grades, then calculates and displays the class average, highest score, and lowest score.

## Features
- Input validation for numerical grades (0–100 range).
- Dynamic student list management using `ArrayList`.
- Automated calculation of average, top performer, and lowest score.

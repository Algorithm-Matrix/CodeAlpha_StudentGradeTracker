# CodeAlpha - Student Grade Tracker (Task 1)

A Java application that enables teachers or administrators to track student grades, validate inputs, and compute statistical analysis such as average grade, top performance, and lowest score. Built for the **CodeAlpha Java Programming Internship**.

## 📌 Features
- **Input Validation**: Ensures grades fall strictly within the valid range ($0 - 100$).
- **Dynamic Data Storage**: Manages arbitrary student lists dynamically using Java `ArrayList`.
- **Statistical Analytics**: Automatically computes class average, maximum score, and minimum score.
- **Summary Dashboard**: Displays formatted tabular output of student results.

## 🛠️ Built With
- **Language**: Java (JDK 17+)
- **Concepts Used**: Object-Oriented Programming (OOP), Java Collections Framework (`ArrayList`), Exception Handling & Validation.
